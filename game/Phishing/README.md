# Badger Mail Quest: The Missing Tail

A one-scene, indie pixel-style phishing game built with plain HTML, CSS, and JavaScript. It opens with a short 8-bit cutscene in Morgridge Hall: Bucky panics after losing his tail and sends a campus-wide email asking for help. After the send animation, click **Continue** to start the game.

## How to play

Bucky’s desktop has UW Mobile Order, UW Free Food, UW Events, and UW News shortcuts. The Badger Mail icon flashes to show Daisy’s new message. Click it, select all five suspicious details in the email, then click **Report phishing**. Missing a clue triggers the corrupted-computer animation and a short explanation.

## Run the game

Double-click `index.html`, or double-click `Start-Badger-Mail-Quest.bat` to open it in your browser. The game has no AI or external service dependency; its scoring and clue feedback run in the browser.

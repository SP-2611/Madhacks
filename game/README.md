# The Tale of the Badger: game folder

- `index.html`: the **full game** (double-click to play in Chrome).
- `1-party/scenes/test.html`: the **scene tester**. Jump straight into any Chapter 1 scene.
- `1-party/`: Chapter 1 code (`core.js` + one file per scene in `scenes/`).
- `2-burrow/`, `3-phishing/`, `4-coursework/`, `5-narcan/`: the other chapters, numbered in play order. Each runs on its own and returns to the Burrow when finished.

See the root README for the full flow.

Controls (Ch 1): WASD move · E interact/next · SPACE tail shake · ↑ phone (Esc close, ← → tabs) · ↑↓ + Enter (or 1–4) pick a choice
